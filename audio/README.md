# audio/ — 可选的真实录音

把音频文件按下面的名字放进这个目录，游戏会**自动**用它替换掉对应的合成音层。
缺哪个文件就继续用哪个的合成版本，不会报错、不用改代码。

| 文件名 | 内容 | 建议 |
| --- | --- | --- |
| `wind.mp3` | 风穿过草地/树林的持续环境声 | 30–90 秒，不要有明显的人声、车声、鸟叫 |
| `rain.mp3` | 中等强度的雨声 | 30–90 秒，最好是"雨打在草木上"而不是打在铁皮/伞上 |
| `birds.mp3` | 稀疏的鸟鸣环境 | 60–120 秒，背景干净，鸟叫之间要有间隔 |
| `crickets.mp3` | 黄昏的虫鸣 | 30–90 秒 |
| `thunder.mp3` | 一声雷 | 3–8 秒的单次音效，不是循环 |

## 说明

- **不需要事先做成无缝循环**。加载时会把结尾一段等功率交叉淡化到开头再裁掉尾巴，
  任何素材都能循环起来（`_makeSeamless()`）。
- 格式用 **.mp3**，iOS 和安卓都支持。`.ogg`/`.opus` 在旧 iOS 上放不出来。
- 音量不用调，游戏里会按天气和风力做淡入淡出；素材本身响度尽量一致就行。
- 单个文件建议控制在 1–3 MB，太大手机上首次加载会等很久。
- 加载是后台进行的，不会挡住游戏开始；没加载完之前先用合成音顶着。
