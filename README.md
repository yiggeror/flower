# 花 · Flower

一个致敬陈星汉《Flower》的网页端 3D 体验。

你操控的不是一个角色，而是**一群飘浮的花瓣**。它们掠过起伏的草原，
所经之处，鲜花从草丛里一朵一朵地顶开、绽放。天气会自行流转，
云在天上聚散，云影在地上缓缓爬过草浪。

纯 WebGL2 / Three.js 实现，无需构建步骤，无外部资源依赖。

---

## 玩

**在线**：https://yiggeror.github.io/flower/ （推到 `main` 后由 GitHub Actions 自动部署）

**单文件**：`dist/flower.html` —— 整个游戏打包成一个 HTML，双击即可运行，
不需要服务器也不需要联网。站点上也提供在 `/download/flower.html`。

**本地开发**：

```bash
npx http-server -p 8080 -c-1 .
# 打开 http://localhost:8080/
```

必须用 http:// 而非 file://，因为源码是拆分的 ES Module。
（`node build.mjs` 生成的单文件版没有这个限制。）

## 画面构成

**起伏的地形**
CPU 生成 513² 的高度场（大丘陵 + 山脊骨架 + 缓谷 + 细节噪声，出生地附近压成一片开阔缓坡）。
高度场同时以数据纹理送进 GPU，草和花在顶点着色器里用手写双线性采样取高度 ——
采样与地形网格顶点严格对齐，所以草不会浮空也不会陷进地里。

**风格化草坪与风吹麦浪**
两层 GPU 实例化草叶（近景约 19 万株、远景约 28 万株），随玩家在世界里取模平铺，
一次 draw call。风场由多频正弦阵风 + FBM 扰动叠加而成：大尺度阵风波负责"麦浪"的主旋律，
波峰处叶片被压向同一角度而成片反光，于是能看见光的波纹在草原上跑。
草的主光方向用「地形法线 × 叶片法线」的混合 —— 草地整体读作一个受光平面，
叶片法线只负责细节，否则近处的草会变成一丛黑刺。

**体积云与地面云影**
天空中的云是半分辨率的光线步进：2D 覆盖场 × 高度剖面 － 3D 侵蚀噪声，
带风切变（云顶顺风偏移，云才不是一根根竖直的柱子），
朝太阳做短程步进得到自阴影，再加多次散射近似避免云背面死黑。

关键在于：**地面的云影和天上的云用的是同一个覆盖场**。
着色点沿太阳方向投影到云层高度再采样，所以"天上那片云"和"地上那块阴影"
永远是同一块云，云飘过去，影子跟着爬过草浪。

**花瓣主角**
领队沿玩家的意志前进并记录路径；每片花瓣按各自的延迟采样这条路径，
再叠加螺旋偏移与颤动 —— 于是得到一条会呼吸的花瓣飘带，而不是一坨跟随的粒子。
花瓣极薄，着色以透光为主：背光时整片透亮，边缘发光。

**所到之处，鲜花绽放**
一张 1024² 的世界空间"绽放贴图"覆盖整个地图。花瓣飘过时往图里加性喷涂一笔（每帧几个极小的四边形）。
花朵实例的位置在世界里是固定的伪随机分布，**开不开、开多大完全由这张图决定**：
每朵花有自己的开放门槛，于是花海会错落地、逐渐地沿着你走过的路蔓延开。
同一张图还会让地面变翠、让草矮下去给花让位。

**声音**
全部用 WebAudio 实时合成，不引入任何音频文件（所以整个游戏仍然是一个 HTML）。
只有自然环境声，没有配乐：

| 听到的 | 由什么驱动 |
| --- | --- |
| 风：低频呼啸 + 草叶摩擦 + 强风的高频哨音 | 场景风力 + 花瓣飞行速度 |
| 雨：分三个频段的雨幕 | 天气系统的降雨量 |
| 雷 | 闪电之后 0.35~1.75 秒（先见闪电，后闻雷声） |
| 鸟鸣 | 天气；下雨不叫，风大时变稀疏 |
| 虫声 | 只在暮色与雨后 |

鸟鸣用带滑音和快速颤音的正弦模拟 —— 鸟叫的关键是音高在几十毫秒内滑动，
而不是一个固定的"哔"。虫声是 Q=22 的窄带噪声被 38Hz 与 1.7Hz 两层脉冲切开，
窄带滤波会衰减约 40dB，所以后面接了一级补偿增益。

**天气**
晴 / 云涌 / 骤雨 / 雨霁 / 暮金。每种天气是一整套环境参数，
切换时阳光、云量、云影强度、雾、地面雾气、风向风力、湿度、曝光**一起**平滑过渡，
所以画面在任何一个中间时刻都是自洽的。雨天有实例化雨丝与偶发的闪电提亮。

**后期链**（自建，不用 EffectComposer —— 需要精确掌控深度缓冲与半分辨率）

```
场景 → 体积云 + 地面雾气(半分辨率光线步进) → 合成
     → 景深 → 多尺度泛光 → ACES + 分离色调 + 暗角 + 颗粒 → FXAA → 屏幕
```

景深的弥散圆在焦点前后各留一段"安全区"：主体和它脚下的地面保持清晰，越远才越虚。
停驻时光圈开大、视角收窄、镜头推近 —— 这是《Flower》最动人的那一刻。

## 性能

四档画质，按实测帧耗时自动升降（草与花的实例数、体积云的步进数与分辨率一起调整）。
移动端默认从低档起步。实例数组在生成后做过洗牌 —— 降档是靠截断 `instanceCount` 减量的，
若保持网格生成顺序，截断会整块地砍掉世界的一侧。

可用 URL 参数覆盖：`?tier=0..3`、`?grass=`、`?flowers=`、`?petals=`、
`?atmos=`（云雾分辨率比例）、`?csteps=`、`?w=0..4`（指定天气）、`?dpr=`。
